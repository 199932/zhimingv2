# 知命V2 坑账本（pitfalls）· 必读集

> 改代码前先扫下面 20 条（约 1 分钟），全量条目按域查 `docs/pitfalls/`。
> 引用格式：`坑42`。新坑写进对应分域文件（见维护规则）。
> 最后整理：2026-11-25（账本分层：必读集 + 六分域）。

## 必读 20 条（每次改代码前扫这 20 条）

1. **坑1** 隐藏/移除类修复，断言必须「元素不存在/视觉截图」，禁止「选择器没匹配到」当证据。
2. **坑2** 一次改动碰多锚点，每锚独立验证（BUILD 漂移 8 轮才暴露）。
3. **坑4** patch 落盘后立即 rg 读回断言；沙箱文件系统会异步回滚吞内容。
4. **坑5** 线上功能终极证据 = 无头浏览器开线上 URL 实测渲染，源码串比对不算数。
5. **坑7** node --check 语法 OK ≠ 运行 OK，必须浏览器 typeof。
6. **坑10** terser 会内联删除局部函数定义；产物完整性断言用字符串常量（卡片标题）+ window.* 属性名 + 行为验证。
7. **坑13** catch(_) 吞错会让一切字符串断言失效——函数级探针 > 推理（坑27）。
8. **坑22** python patch 被 assert 拦截 = 整包未写盘，但同一 bash 链后续命令照跑（build 出旧产物）——fail-fast 后整套重写 + 读回。
9. **坑31** rg 显示层会吞字符序列（`[m`/`[hi`）——断言只信 rg -l/-c 的 rc，或 python re.search 读真实字节一锤定音。
10. **坑34** 引用既有接口先 rg 函数名 + 返回字段双向验证；typeof 防御检查静默 fallback 会藏 bug 9 天。
11. **坑39/40/46（撞名三合一）** 新增 window.*/模块前缀/全局名，一律先 rg 全文件查占用——输出禁止截断（撞名=静默覆盖，功能悄悄死）。
12. **坑47** onclick 引用函数必须显式挂 window，线上验真逐按钮 typeof（A 钮能响 ≠ B 钮能响）。
13. **坑54** details 折叠子元素带 display 值会覆盖 UA 收起隐藏——配对写 `.fold:not([open])>.child{display:none}`。
14. **坑57** 裸 fixed div 弹层是 esc 栈/mask/已知弹窗三管兜底的盲区——新弹层必须在 esc + 切页两处显式注册。
15. **坑58** 跨模块双数据源只在单点写入 = 切档后滞留旧值——副本类存储必须挂主档变更双钩同步。
16. **坑75** mock 档案 ≠ 排盘表单值（fillFormWithProfile 时序）——排盘类验证显式 set 表单再 calc；档案 mock 用 addInitScript 在 boot 前塞（坑76）。
17. **坑93** 「注释与实现不一致」是独立债种——复核代码路径，永远不信注释。
18. **坑139** 插入 section 后跑「全 section 容器归属普查」——单点验证会漏孤魂（子签高亮内容空白）。
19. **坑140** 版本断言只用「ZHIMING_BUILD = 'vX'」专属前缀串；裸版本号 count 会被注释污染（v2.142 三版静默没升）。
20. **坑144** 多步 patch 中断 = 后续步骤全未执行，比失败更危险的是「成功的丢失」——每步独立验证 + 产物断言逐 mod 验；patch 中断后恢复 git 基线整套重写，不续跑（配坑145：write 永远放断言全过后）。

## 维护规则

1. **新增坑写进对应分域文件**，追加到末尾、编号递增——pitfalls.md（本文件）只在「必读集」变化时动。
2. 进必读集的门槛：**复发过 2 次以上**、或**单次损失 ≥ 半天**、或**属于会静默失效（不报错）**的坑。进必读时同时把本条从必读里最旧的、已形成肌肉记忆的条目顶出去，总数恒 ≤ 22。
3. 修 bug 前先 rg 账本关键词（坑138：知识必须进迭代回路，不是归档）。
4. CI 账本新鲜度提醒（build-check 里的非阻断 step）盯的是全部分域文件 + 本文件的 last-commit 时间。
