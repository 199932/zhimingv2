# 知命 V2 · 每日身心助手

纯本地、无联网的**每日身心助手**：以「今日页」为唯一主入口（此刻最该做 + 黄历 + 时段策略），命理占卜是其中一个工具箱模块。所有计算与数据均在本机完成，不上传任何个人信息，离线可用（PWA）。

**在线使用**：https://199932.github.io/zhimingv2/

## 产品主轴（新模块准入判断）

**今日页是唯一主入口，其余模块是工具箱。** 任何新模块先回答「它属不属于今日主轴」——
即：能否出现在「此刻最该做」的推荐链路里（晨记/午休/饭点/深夜/情绪/心率等信号源），或能否被今日页直接调用。不属于就进工具箱分组，不进今日页。

## 特点

- **隐私优先**：无账号、无埋点、无数据上传，所有数据仅存于浏览器 localStorage
- **离线可用**：Service Worker 缓存，安装到桌面后无网也能用
- **纯前端**：单页应用，零后端依赖
- **多主题**：浅色 / 深色 / 中式 / 西玄 / 黄历等主题随页切换

## 安装

手机浏览器打开站点 → 菜单「添加到主屏幕」，或站内顶栏「安装到桌面」。

## 隐私说明

应用不收集、不上传任何用户数据。出生信息等仅存储于浏览器本地，清除浏览器站点数据即彻底删除。

## 构建（v2.30.0 起三件套架构）

源码在 `src/index.html`（单文件，含全部内联 CSS/JS），**根目录 index.html / assets/app.js / assets/style.css 是构建产物，勿直接手改**。

```bash
node build.js   # src/index.html → 根产物（terser 压缩 JS、压缩 CSS）
```

改动流程：编辑 `src/index.html` → `node build.js` → 本地打开根 index.html 验证 → 提交全部变更。sw.js 的 PRECACHE 已包含 assets 两文件，离线可用不受影响。
